# coderstech.github.io

## Printing the resume

Print any resume variant on A4 or US Letter paper at the default scale, with browser headers and footers disabled. Select page 1 for the professional resume; page 2 contains the optional volunteer and personal details. The printed resume keeps its two-column design, so text reading order may vary between ATS parsers.

The resume skills are listed in `_data/resume_skills.yml`; uncomment the Java entry if needed.
