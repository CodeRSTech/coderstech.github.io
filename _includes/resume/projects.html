https://coderstech.github.io/AI-Pong/

A Neural Network based Genetic Algorithm finds the optimal solution for playing 2d game, pong.

Technology Arcade/Pygame, Torch/NumPy, Torchvision

Source codehttps://github.com/CodeRSTech/AI-Pong

Over 100 individuals evolve to play the game "Pong" over multiple generations. At the end of each generation, top performers create their unique offspring. This cycle is repeated several times. Initial built on Pygame + NumPy, it was rebuilt using Arcade + Torch for better performance.
